How to use MindFort

  1. Launch the app and complete onboarding.
  2. On iPhone or iPad, grant Screen Time permission when prompted.
  3. Create a focus profile or choose a template.
  4. Select apps, app categories, or websites that are compatible with the current device.
  5. Start a timed or open-ended focus session from the Focus tab.
  6. Choose whether to start only on this device or start here and ask MindFort to try your other devices.
  7. Use Schedules to automate blocking by day and time.
  8. Use Limits to set a daily time limit or a fixed number of timed opens.
  9. On iPhone or iPad, open Actual Screen Time to review day, week, month, or year.
  10. Turn on the weekly focus report in Settings if you want a summary each week.

Screen Time permission

On iPhone and iPad, app, category, and supported website protection requires Apple's Screen Time permission. MindFort cannot protect those selections on a device until permission is granted there.

Actual Screen Time is also available on iPhone and iPad. Apple's private report calculates app and category durations and pickup counts on the device. MindFort can additionally keep local estimates of how often its block screen appeared for your own focus statistics. These measurements are not sent to the MindFort developer or a developer-operated analytics service.

Mac app and website protection

On Mac, MindFort can close selected native applications while focus protection is active. This selection is local to the Mac and is separate from iPhone and iPad Screen Time selections.

Mac website protection uses built-in network controls and MindFort's support for compatible browsers. The first use may require approval in macOS System Settings and Automation access. Firefox can still be blocked but may show its own error page instead of the MindFort block page. Network privacy settings such as Private Relay or encrypted DNS can prevent website protection in some configurations.

Daily limits

A time limit tracks daily use for the selected profile until the set duration is reached. Timed opens provide a fixed number of temporary access periods. Limit definitions can sync through iCloud, but each device measures its own use and applies protection separately.

Difficulty levels

Easy sessions can end immediately. Medium sessions add a 30-second pause before ending. Hard Mode can only be ended early with an Emergency Pass; each device gets 3 Emergency Passes per day.

Easy and Medium sessions include 3 breaks per day on each device. Use Take a break in the app or on the Live Activity; the block screen shows how many breaks are left. Breaks are not offered in Hard Mode or during a schedule. Emergency Passes and breaks are counted separately on every device and reset each day.

Focus across devices

Start on this device affects only the current device. Start here and try other devices sends an automatic start request to other MindFort devices signed in to the same Apple Account. A device starts only after the change reaches it and the synced profile, compatible local selections, required permission, and no conflicting focus are ready there.

Stop on this device ends only local protection. Stop on all active devices ends the shared focus for every device taking part. iCloud delivery is asynchronous, so MindFort does not claim that an idle device is currently online or fully up to date.

Data and account deletion

MindFort does not require a separate MindFort account. Profiles, schedules, limit definitions, focus session history, and cross-device focus records can sync privately through iCloud between devices using the same Apple Account. Detailed Screen Time reports remain on the device that provides them.

Deleting the app removes its local data from that device, but it does not automatically delete data already synchronized to iCloud. That data may synchronize again after a reinstall or on another signed-in device. To remove the cloud copy, manage or delete MindFort data from your Apple Account's iCloud storage settings; exact menu names vary by operating-system version.
