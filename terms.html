Service description

MindFort is a focus and digital wellbeing app for iPhone, iPad, and Mac. It provides focus sessions, reusable profiles, recurring schedules, daily limits, focus statistics, and optional private iCloud coordination between compatible devices using the same Apple Account.

On iPhone and iPad, MindFort uses Apple's Screen Time controls to protect selected apps, app categories, and supported websites. On Mac, MindFort can close selected native apps while protection is active and filter selected website domains in supported browsers.

User responsibility

You are responsible for your own protection choices, profiles, schedules, limits, and device permissions. MindFort provides tools for self-management; it does not guarantee productivity, wellbeing, or behavioral change.

Limitations

App and website protection depends on Apple Screen Time and macOS application and network controls. Availability varies by platform, operating-system version, browser, selected target, permission, Private Relay, and encrypted DNS settings. Protection may therefore be unavailable or incomplete in some configurations.

Cross-device coordination uses private iCloud delivery, which is asynchronous. Starting or stopping on all devices attempts to update currently available, compatible devices automatically; it does not guarantee an immediate update on a closed, offline, unauthorized, conflicting, or not-yet-synced device. Daily limit consumption, enforcement state, permissions, Hard Mode Emergency Passes, and break allowances remain local to each device.
