App Review Note: MindFort is a focus and distraction-blocking app using Apple's Screen Time, Family Controls, DeviceActivity, ManagedSettings, ShieldAction, and ShieldConfiguration frameworks. No account is required.

How to Use MindFort

  1. Launch the app and complete onboarding.
  2. Grant Screen Time permission when prompted.
  3. Create a focus profile or choose a template.
  4. Select apps, app categories, or Safari website domains to block.
  5. Start a focus session from the Focus tab.
  6. Use Schedules to automate blocking by day and time.

Screen Time Permission

Blocking requires Apple's Screen Time permission. MindFort cannot block selected apps until permission is granted by the user.

Website and Browser Blocking

Safari website restrictions are supported for website domains. To block Chrome, Firefox, Opera, or other browsers, select those browser apps in a focus profile.

Data and Account Deletion

MindFort does not require an account and does not store data on external servers. To delete local MindFort data, delete the app from the device. iOS removes the app's local data with the app.

Purchases

The initial submitted build does not include active in-app purchases, subscriptions, paywalls, or paid feature locks. All visible features in the submitted build are available without purchase.
